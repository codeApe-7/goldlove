# 当前功能清单（前端原型设计依据）

> 更新日期：2026-08-22
> 用途：作为访客端与管理后台前端设计的功能依据。
> 对应代码：`apps/guest-app`（访客端 H5，uni-app）、`apps/admin-web`（管理后台，Vue3 + Element Plus）、`services/platform-api`（后端 API）。
>
> 上一版（2026-08-09）描述的是「付费登记发初始凭证 + 档案送审」的旧形态，
> 那套流程已在「简化为免费注册 + VIP」重构中整体移除：**没有初始凭证，也没有审核环节**。

## 1. 产品形态与核心流程

双端 Web（H5）+ 后端 API：

- **访客端**（uni-app，现已跑在 H5，架构预留微信小程序）：
  手机号 + 密码**免费注册**（注册即签《档案与直播内容授权书》）→ 填写档案（**保存即对管理员可见，无审核**）→
  上传头像与生活照 → 需要时升级 VIP（在线支付或兑换激活码）。
- **管理后台**（Vue3 + Element Plus）：
  管理员登录 → 工作台看数据 → 档案管理（查看 / 筛选 / 导出 / 停用账号）→
  支付订单台账 → **生成激活码**（线下收款后发码，取代了旧的「登记发初始凭证」）→ 配置档案字段。

## 2. 访客端页面

底部 Tab：档案 / 我的，共 6 个页面（含一个不进 Tab 的设计规范预览页）。

| 页面 | 路径 | 元素与交互 |
| --- | --- | --- |
| 登录 | `/pages/auth/index` | 品牌标题；手机号 + 密码；底部「还没有账号？注册建档」入口 |
| 注册 | `/pages/register/index` | 手机号、密码、确认密码；勾选《档案与直播内容授权书》（可就地展开正文）；注册成功直接登录 |
| 档案 | `/pages/profile/index` | 完整度进度条 + 四组字段卡片 + 照片区 + 「保存档案」（详见 2.1） |
| 我的 | `/pages/mine/index` | 账号信息、会员等级；《档案与直播内容授权书》可就地展开；会员页入口；退出登录 |
| 会员 | `/pages/vip/index` | 当前等级与累计付费；在线支付升级（易支付整页跳转后回跳查单）；激活码兑换 |
| 设计规范 | `/pages/design/index` | 按《H5 表单组件与下拉样式规范 v1.0》逐区块陈列组件状态，**不在 Tab 内**，仅供设计验收 |

### 2.1 档案页字段（由后端字段配置驱动，当前启用项）

控件由 `utils/profileControls.ts` 按 `fieldCode` 认领，其余按 `dataType` 兜底。

| 字段 | 类型 | 交互 |
| --- | --- | --- |
| 性别 | 单选 | 并排格子单选：男 / 女 |
| 出生日期 | 日期 | 底部弹层，年 / 月 / 日三列滚轮 |
| 身高（厘米） | 整数 | 数字输入 |
| 学历 | 单选 | 底部弹层滚轮：博士及以上 / 硕士研究生 / 大学本科 / 大专 / 高中及以下 / 其他学历 |
| 职业 | 单选 | 底部弹层滚轮（**职业范围**，不是具体岗位）：互联网 / IT、金融 / 投资、教育 / 培训、医疗 / 健康、法律 / 咨询、政府 / 事业单位、其他行业 |
| 年薪 | 单选 | 底部弹层滚轮：20万以下 / 20万-30万 / 30万-50万 / 50万-80万 / 80万-120万 / 120万以上 / 保密（选「保密」加锁标，不展示具体区间） |
| 所在城市 | 文本 | 省 / 市 / 区三级联动（全国 34 省级、344 地级、3104 县级），结果按「北京市 / 东城区」拼成文本存回 |
| 微信号 | 文本 | 输入框 |
| 抖音号 / 抖音昵称 / 抖音主页链接 | 文本 | 输入框，**均为选填** |

照片区：

- 头像：必填 1 张；再次上传直接覆盖旧头像。
- 生活照：最多 6 张；可删除（×）。
- 单张 ≤ 10 MiB，仅 JPEG / PNG / WebP，最小 64×64（后端校验真实格式）。
- **上传只把对象暂存到 COS，保存档案时才写入档案**；保存时移除的照片会在事务提交后删除 COS 对象。
## 3. 管理后台页面

侧边栏分三组：**数据**（工作台、档案管理）、**运营**（支付订单、激活码）、**配置**（字段配置、支付设置）。
共 7 个路由（含登录页）。观感依据《后台组件与筛选控件规范》：主色蓝 `#1D4ED8`、正文 14px、卡片圆角 8px。

| 页面 | 路由 | 元素与交互 |
| --- | --- | --- |
| 登录 | `/login` | 品牌 + 账号 / 密码；会话守卫，未登录自动跳转 |
| 工作台 | `/dashboard` | 6 张统计卡（注册用户、今日注册、累计建档、资料完善、VIP、SVIP）+ 今日概览 + 档案总量 |
| 档案管理 | `/profiles` | 五个状态 tab（全部 / 草稿 / 已建档 / 已停用 / 已付费会员，带计数）；筛选条（关键词、创建时间范围、会员等级、所在地区级联、排序）；工具栏（刷新、导出当前筛选、列设置、生成激活码）；表格（档案编号、手机号、性别、年龄、所在地区、会员等级、完成度、账号状态、创建时间、更多操作）；勾选后可批量导出；点行开右侧详情抽屉 |
| 档案详情 | 抽屉（`/profiles?profile=<id>`） | 头像 + 手机号 + 三个状态标签；tab「资料 / 照片」；右侧操作栏：导出资料、复制链接、停用 / 启用账号。旧路由 `/profiles/:id` 会重定向到这里 |
| 支付订单 | `/payment-orders` | 筛选（手机号、状态）；表格（商户订单号、手机号、金额、状态、渠道、支付时间、下单时间） |
| 激活码 | `/activation-codes` | 筛选（绑定手机号、状态）；「生成激活码」抽屉（手机号、授予等级 VIP/SVIP、备注），生成后就地展示码并可复制；列表可复制、可作废未使用的码 |
| 字段配置 | `/field-definitions` | 表格（字段标识 / 名称 / 类型 / 存储 / 必填 / 启用 / 顺序 / 说明）；「新建字段」抽屉可建动态字段（文本 / 长文本 / 整数 / 小数 / 日期 / 布尔 / 单选）；编辑时核心字段的必填与启用置灰 |
| 支付设置 | `/payment-settings` | 当前生效的 VIP 升级金额 + 来源（后台设置 / 服务器配置）+ 配置回落值 + 最近修改时间 + 只读的商品描述；按元录入改价（¥0.01 ~ ¥100000），保存只影响之后创建的订单 |

**后台是只读的**：没有新建档案、编辑资料、删除档案。档案由访客自助填写，后台不代填。

## 4. 业务规则（原型需体现）

- **账号状态**：注册即 `ACTIVE`。管理员可停用（`SUSPENDED`）与启用；停用后该手机号立刻无法登录或修改档案，
  后台仍可查看其档案。`CLOSED` 是用户自己注销的终态，管理员不能改回来。停用 / 启用的原因备注写入 `audit_log`。
- **档案完成度**：只有 `DRAFT` / `COMPLETED` 两档，保存时按必填字段 + 头像算出来。**没有审核环节**。
- **会员等级**：`FREE` < `VIP` < `SVIP`，只升不降。在线支付累计额度达阈值（默认 ¥599）自动升 SVIP；
  **兑换激活码直接授予等级但不计入付费额度**。
- **激活码**：生成时绑定手机号，只有该手机号的账号能兑换；码明文存库以便管理员复读分发；
  未使用的可作废。注册不做短信验证，**绑定的手机号若未注册，存在被抢注者领走的风险**（列表会标「未注册」）。
- **授权书**：注册时签署，有效期一年；「我的」页可查看当前生效版本正文。
- **照片**：头像唯一（重传即覆盖）、生活照最多 6 张；存腾讯云 COS，预览链接 15 分钟有效、不落库。
- **字段配置**：核心字段固定存在 `guest_profile` 的具名列上，动态字段由后台新增；
  被使用过的字段定义不可改类型 / 代码；核心字段的必填与启用由数据库触发器锁死。
- **导出**：CSV 含完整字段（手机号、微信号、抖音号），单次上限 5000 条，每次导出追加一条审计记录。
