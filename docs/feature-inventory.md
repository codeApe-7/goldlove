# 当前功能清单（前端原型设计依据）

> 更新日期：2026-08-09
> 用途：作为嘉宾端与管理后台前端原型设计（线框/高保真）的功能依据。
> 对应代码：`apps/guest-app`（嘉宾端 H5，uni-app）、`apps/admin-web`（管理后台，Vue3 + Element Plus）、`services/platform-api`（后端 API）。

## 1. 产品形态与核心流程

双端 Web（H5）+ 后端 API：

- **嘉宾端**（uni-app，现已跑在 H5，架构预留微信小程序）：手机号 + 初始凭证激活 → 同意授权书 → 填写档案 → 上传照片 → 提交审核 → 查看状态 / 被退回后修改重提。
- **管理后台**（Vue3 + Element Plus）：管理员登录 → 工作台看数据 → 访客登记发初始凭证 → 审核档案（通过/退回）→ 配置动态字段。

## 2. 嘉宾端页面

底部 Tab：档案 / 状态 / 我的，共 5 个页面。

| 页面 | 路径 | 元素与交互 |
| --- | --- | --- |
| 登录/激活 | `/pages/auth/index` | 品牌标题“婚恋智能档案库”；手机号、初始凭证（仅首次激活）、密码三个输入框；提交后进入档案页。同页承担“激活”与“登录”两种模式 |
| 授权书 | `/pages/consent/index` | 当前授权书标题 + 正文（长文滚动阅读）；勾选“我已阅读并同意”；按钮“同意并继续”进入档案页；未勾选时提示 |
| 档案 | `/pages/profile/index` | 基本信息表单 + 照片区 + 底部“保存草稿”“提交审核”（详见 2.1） |
| 状态 | `/pages/status/index` | 大号状态文字 + 说明文案，按状态区分：待审核 / 已通过 / 被退回（“去修改”按钮跳回档案页）/ 未提交（提示先完善档案） |
| 我的 | `/pages/mine/index` | 账号信息；“查看/重新同意授权书”入口；退出登录 |

| 微信号 | 文本 | 输入框 |
| 抖音号 | 文本 | 输入框 |
| 抖音昵称 | 文本 | 输入框 |

照片区：

- 头像：必填 1 张；再次上传直接覆盖旧头像。
- 生活照：最多 6 张；可删除（×）。
- 提交前校验：必填字段完整、头像已上传。

## 3. 管理后台页面

侧边栏布局：工作台 / 访客登记 / 字段配置 / 审核管理，共 6 个路由页面。

| 页面 | 路由 | 元素与交互 |
| --- | --- | --- |
| 登录 | `/login` | 品牌 + 账号/密码；会话守卫，未登录自动跳转 |
| 工作台 | `/dashboard` | 4 张统计卡：待审核、今日登记、今日审核、累计建档（数字 + 说明） |
| 访客登记 | `/guests/register` | 左栏表单：手机号、付款参考号、付款金额（元）、付款时间、授权书版本、备注；按钮“登记并生成初始凭证”，成功后**一次性展示初始凭证**；右栏“补发初始凭证”：输入手机号 → 生成新凭证并作废旧凭证 |
| 字段配置 | `/field-definitions` | 字段表格（字段代码/名称/类型/存储/必填/启用/编辑）；“新增字段”可建动态字段（文本/长文本/整数/小数/日期/布尔/单选）；编辑时核心字段仅可改名称、选项、排序、说明，类型与代码不可改 |
| 审核管理（列表） | `/reviews` | 筛选：状态（待审核/已通过/已退回）、截止时间（即将超时/已超时）、档案编号搜索；表格：版本 ID、版本号、档案编号、状态标签、提交时间、审核截止；分页；点击行进详情 |
| 审核详情 | `/reviews/:id` | 返回；档案信息两列描述（编号、状态、性别、出生日期、身高、学历、职业、年薪、城市、微信号、抖音号、提交/截止时间）；照片墙（点击放大预览）；“与最后已通过版本的差异”表（字段/原值/新值）；待审核时显示“通过”（确认框）与“退回”（必填退回说明输入框） |

## 4. 业务规则（原型需体现）

- **账号状态**：付费登记（PAID_PENDING_ACTIVATION）→ 初始凭证激活后 ACTIVE；凭证一次性，可补发（旧凭证作废）。
- **档案状态机**：草稿 DRAFT → 待审核 PENDING_REVIEW → 已通过 APPROVED / 被退回 CHANGES_REQUESTED → 修改后再提交（提交幂等；审核截止为提交后 24 小时）。
- **授权书**：有当前生效版本，同意后有效期一年；授权到期/未同意时不可建档，我的页可重新同意。
- **照片**：头像唯一（重传即覆盖）、生活照最多 6 张；存腾讯云 COS，下载链接 15 分钟有效；已归档版本引用的照片对象不会被物理删除（快照保护）。
- **字段配置**：核心字段固定存在档案列，动态字段由管理后台新增；被使用过的字段定义不可改类型/代码。
- **退回说明**：管理员退回时填写说明（后端已存储），嘉宾端当前仅显示“档案被退回，请修改后重新提交”通用文案，**未展示具体原因**——原型建议预留“退回原因”展示位。
